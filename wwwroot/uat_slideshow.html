ระบบต้นแบบ (Prototype)

แพลตฟอร์มจัดการเรียนรู้และระบบปฏิบัติการหลังบ้านโครงการความร่วมมือการพัฒนาฝีมือแรงงานอาชีวศึกษา (SkillsLao TVET Platform)

Introduction

1. วัตถุประสงค์ของการทดสอบระบบ

เป้าหมายการทดสอบระบบต้นแบบ

  • ความสมเหตุสมผล (Process Logic): ตรวจสอบความถูกต้องของขั้นตอนการกดสลับหน้าจอ (Screen Flow) ในแต่ละ Use Case
  • ความง่ายในการใช้งาน (Usability & Copy): ตรวจสอบคำอธิบาย ขนาดปุ่มกด ภาษาที่ระบุ และข้อมูลแสดงผลในตารางหลังบ้าน
  • การเก็บข้อมูลป้อนกลับ (Feedback): รวบรวมข้อติดขัดเพื่อจัดส่งต่อเป็นความต้องการที่สมบูรณ์ให้ทีมเขียนโค้ดจริงระบบจริงต่อไป

โปรดเข้าใจ: นี่คือระบบต้นแบบ (Prototype)

ระบบทั้งหมดทำหน้าที่จำลองหน้าตาและการทำงานจำลองเท่านั้น ข้อมูลที่มีการบันทึกหรือกรอกลงในเว็บทั้งหมดคือข้อมูลตัวอย่าง ไม่ส่งผลกระทบต่อฐานข้อมูลระบบจริงใด ๆ ทั้งสิ้น ไม่ต้องกังวลว่าระบบจะเสียหาย

ระยะเวลาทดสอบระบบต้นแบบ

เราจำกัดเป้าหมายเวลาการทดสอบของทุกกลุ่มให้อยู่ภายใน 90 นาที เพื่อความกระชับและไม่ดึงเวลาการทำงานหลักของผู้ร่วมรีวิวระบบต้นแบบทุกคน

How to Test

3. วิธีควบคุมและทดลองรันสถานการณ์ (Harness Bar)

การใช้ Scenario Harness Bar (แถบด้านบน)

ที่หัวมุมบนของทุกหน้าจอต้นแบบจะมีแถบตัวเลือกจำลองฉากทำหน้าที่ควบคุมสถานะหน้าเว็บเพื่อทดสอบเคสต่าง ๆ:

  • Main Flow / Happy Path: เริ่มต้นด้วยเคสปกติ ทำงานราบรื่นและสิ้นสุดสมบูรณ์แบบ
  • Alternative Flow (AF-xx): จำลองสถานการณ์เกิดเรื่องอื่น ๆ เช่น อัปโหลดไฟล์ผิดประเภท, กดถอยกลับ หรืออินเทอร์เน็ตขาดหายกลางคัน

หน้าจอแสดงผลสถานะ Pending

หากหน้าจอดังกล่าวระบุคำว่า Pending หรือปุ่มกดแสดงสถานะสีจืดไม่สามารถคลิกเชื่อมโยงหน้าต่างได้:

  • หมายถึง Use Case นั้นไม่ได้อยู่ในการพัฒนาของตัวจำลองต้นแบบนี้
  • คำแนะนำ: ไม่ต้องตกใจ ให้เปิดไฟล์ Excel ในแถว Use Case นั้น ๆ และเลือกผลการทดสอบเป็นช่อง N-T (Not Tested) ทันที เพื่อข้ามไปทำข้อถัดไป
Feedback Rubric

4. การกรอกประเมินลงตาราง Excel (Feedback Sheet)

Result (ผลลัพธ์)

ป้อนผลลัพธ์การทำงาน:
Pass = ทำงานได้ราบรื่น
Fail = มีปัญหา ขั้นตอนไม่ตรง หรือจุดสับสน
N-T = หน้านั้นกดทดสอบไม่ได้ (Not Tested)

Ease (ระดับความง่าย)

ประเมินความพึงพอใจการตอบสนอง คะแนนตั้งแต่ 1 ถึง 5:
1 = หายากมาก สับสน หาปุ่มไม่เจอ
5 = ใช้งานง่าย ทราบขั้นตอนทันที

Remark (ความคิดเห็น)

เขียนข้อความระบุสิ่งที่เกิดขึ้น เช่น ปุ่มไม่เห็นเด่น, คำแปลภาษาลาวสับสน, หรือต้องการฟิลด์เพิ่มเติมในระบบจริง
